What's kept

  • Your message's text is never stored. It's only read, in memory, to check the DKIM signature.
  • Each test is deleted from the test mailbox as soon as it has been checked (and its report sent or given up on).
    • {% if v.public_url %}
  • For the website, the report is kept: the message's headers and the results of the checks. It expires {{ v.viewed_minutes }} minutes after it's first shown here, or after {{ v.unviewed_hours }} hours if nobody looks, and is then deleted at the next clean-up. Viewing a report also deletes older reports for the same address, and only the most recent {{ v.max_results }} reports are kept.
    • {% else %}
  • Reports aren't kept: they're only emailed.
    • {% endif %}
  • To enforce the limits, the service counts lookups and reports per network and per address. It stores those as salted hashes, not as IP addresses or email addresses, for a day.
  • The service's logs record counts and reasons, never addresses.

Who can see a report

The website looks reports up by the address they were sent from (the From: address or the envelope sender), so anyone who knows that address can view its latest report while it's kept, and viewing it starts its {{ v.viewed_minutes }}-minute clock. A report holds only what's in the test's headers and public DNS records, never the message's text, so send tests without anything private in their headers, such as the subject.

Links in the emailed reports use a random code, and the address is never part of any web address on this website, so it isn't kept in browser histories or web server access logs.

The website

  • No cookies, no tracking, no JavaScript and nothing loaded from other websites.
  • Search engines are asked not to index any of it.
  • Forms posted from other websites are refused, so another site can't look up a report and start its clock.
