Each test's report is also kept on this website for a short time. It's the same report as the email, and it's there as soon as the test has been checked, even when no report was emailed.

Look up by address

  1. Go to the home page.
  2. Enter the address you sent the test from (not the test address) and press View Report. The envelope sender (Return-Path) address works too, but some services share one between many senders, so the From: address is the safer choice. Capital letters don't matter.

You'll see the most recent report for that address. Viewing it deletes any older reports for the same address. If there's no report, the page says so. It says the same thing whether or not that address has ever sent a test.

Lookups are limited to {{ v.lookups_minute }} a minute and {{ v.lookups_hour }} an hour per IP address, so people sharing one (an office or a VPN) share the allowance. Every press of View Report or Check again counts, even when there's no report, but opening an email's link, or downloading the headers from a report on screen, doesn't.

The address you enter is sent with the form, not as part of the page's web address, so it isn't kept in your browser history or in the web server's access logs.

The link in the email

The emailed report ends with a link to its copy online. Opening the link shows a View Report button: press it to see the report.

The button is there because many mail systems open every link in an email to scan it for danger. If the link showed the report straight away, a scanner could start the report's self-destruct clock before you'd seen it.

Each link is a random code that can't be guessed, and it only ever shows that one report.

Why reports self-destruct

Reports are kept only as long as they're useful:

  • A report that nobody looks at online expires after {{ v.unviewed_hours }} hours.
  • Once it's been shown on this website, it expires {{ v.viewed_minutes }} minutes later. A red banner at the top says how many minutes were left when the page loaded.
  • Only the most recent {{ v.max_results }} reports are kept, so on a busy day an older report can go sooner.

Need it for longer? Keep the emailed report, or save or print the report page. The Download the full email headers (.txt) button saves just the test's headers. More on what's kept in Privacy and limits.

The website and the email

The report online says exactly what the email says, box by box, with one difference. The email can tell you that the reply reached the domain, because you're reading it. The website can't know that, so when the domain has MX records, its "Can receive email" row shows ? with "Unknown: this is only available in the emailed report", and its overall status is never "All Tests Passed". (Missing MX records still show as a failure.)

The website also doesn't show the summary picture that's attached to the email. For the full check, use the emailed report.
