All settings live in the .env file next to docker-compose.yml, and .env.example lists every one. A missing or invalid setting stops the service at startup with a message naming it. Leave an optional setting out, or empty, to get its default (except SENDING_EMAIL_FROM_NAME, below).

Your own code in the pages

CUSTOM_HEADER_HTML adds your own HTML to the <head> of every page on the website, this documentation included, such as the script for a visitor statistics service. It's left off the pages that report links open, since their address is the key to a report and shouldn't reach anyone else's records, and off pages that don't exist. Wrap the HTML in single quotes in .env and write \' for a quote inside it. It can span several lines.

CUSTOM_HEADER_HTML='<script defer src="https://stats.example.com/script.js"></script>'
CUSTOM_HEADER_CSP='script-src https://stats.example.com; connect-src https://stats.example.com'

The pages' Content-Security-Policy blocks anything not allowed by name, so CUSTOM_HEADER_CSP lists what your code may load, directive by directive, separated by semicolons. It can add to script-src, connect-src, img-src, style-src, font-src, frame-src, media-src, worker-src and manifest-src. Inline <script> and <style> blocks in CUSTOM_HEADER_HTML are allowed automatically, by their hashes. Attributes like onload= and style= aren't, so put that code in a block instead. For the same reason script-src can't take 'unsafe-inline', 'unsafe-hashes', data: or 'unsafe-eval', which would let any inline script, or code in a string, run. Write script and style blocks out in full (<script>...</script>), not as <script/>. The pages send no referrer, so requests your code makes don't carry the page's address unless the code sends it itself (statistics scripts do).

Allowed values

Retention times and lookup and email limits must be whole numbers of at least 1: zero doesn't turn them off. TRUSTED_PROXY_HOPS may be 0, POLL_SECONDS must be at least {{ v.min_poll }}, and SENDING_EMAIL_PORT must be from 1 to 65535.

On/off settings (SENDING_EMAIL_USE_TLS, DRY_RUN, DOCS_ENABLED) take True or False, in any capitalization. Anything else, like yes or 1, is refused at startup.
