All settings live in the .env file next to docker-compose.yml, and .env.example lists every one. A missing or invalid setting stops the service at startup with a message naming it. Leave an optional setting out, or empty, to get its default (except SENDING_EMAIL_FROM_NAME, below).

Mail

SettingDefaultWhat it's for
RECEIVING_EMAIL_ADDRESS requiredThe address people send tests to. It's never answered, nor is anything else at its domain.
RECEIVING_EMAIL_HOST, RECEIVING_EMAIL_USER, RECEIVING_EMAIL_PASSWORD requiredThe test mailbox's IMAP login. The user is often the same as the address, but not for an alias.
SENDING_EMAIL_HOST requiredThe SMTP server that sends the reports.
SENDING_EMAIL_HOST_USER, SENDING_EMAIL_HOST_PASSWORDnone (no login)The SMTP login, for a server that needs one (most do).
SENDING_EMAIL_PORT, SENDING_EMAIL_USE_TLS587, TrueTrue starts TLS (STARTTLS) before logging in.
SENDING_EMAIL_FROM, SENDING_EMAIL_FROM_NAMEthe test address, APP_NAMEThe reports' From: address and name. Leave the name out to use APP_NAME, or set it empty for no name.
POLL_SECONDS requiredSeconds between mailbox checks, at least {{ v.min_poll }}.
DRY_RUNFalseTrue: messages are checked, but nothing is sent, flagged or deleted.

DOCS_ENABLED{{ defaults.DOCS_ENABLED }}This documentation, at /docs/, with links to it from the website and the report emails. False turns it off.

Reports and limits

SettingDefaultWhat it's for
TRUSTED_MX_HOSTS requiredYour receiving mail servers' names, comma-separated (see Setup).
APP_NAME{{ defaults.APP_NAME }}The name on the website, the emails and the summary picture.
DISPLAY_TIMEZONE{{ defaults.DISPLAY_TIMEZONE }}The time zone for times in the reports, such as America/New_York.
RESULTS_KEPT_HOURS{{ defaults.RESULTS_KEPT_HOURS }}How long a report is kept if nobody looks it up.
RESULTS_KEPT_AFTER_VIEW_MINUTES{{ defaults.RESULTS_KEPT_AFTER_VIEW_MINUTES }}How long a report is kept after the website first shows it.

MAIL_PER_DAY{{ defaults.MAIL_PER_DAY }}Report emails in total, from everyone: a hard daily ceiling.

Allowed values

Retention times and lookup and email limits must be whole numbers of at least 1: zero doesn't turn them off. TRUSTED_PROXY_HOPS may be 0, POLL_SECONDS must be at least {{ v.min_poll }}, and SENDING_EMAIL_PORT must be from 1 to 65535.

On/off settings (SENDING_EMAIL_USE_TLS, DRY_RUN, DOCS_ENABLED) take True or False, in any capitalization. Anything else, like yes or 1, is refused at startup.
